# MATLAB Bilimsel Hesaplama

Pamukkale Üniversitesi Bilgisayar Mühendisliği bölümünde aldığım **Bilimsel Hesaplama** dersi kapsamında hazırladığım haftalık ders notları, MATLAB çalışmaları ve örnekleri bu repoda bulunmaktadır.

## İçerik

- MATLAB temel kullanım notları
- Değişkenler ve veri türleri
- Matris ve dizi işlemleri
- MATLAB indeksleme
- Matematiksel ve bilimsel hesaplamalar
- MATLAB komutları
- Ders kapsamında hazırlanan örnekler

## Haftalık Notlar

Ders ilerledikçe haftalık ders notları bu repository içerisinde düzenli olarak paylaşılacaktır.

## Amaç

Bu repository, Bilimsel Hesaplama dersi boyunca tuttuğum notları düzenli bir şekilde saklamak ve MATLAB öğrenme sürecimi takip etmek amacıyla oluşturulmuştur.
